## 🧠 Problem-Solving Approach

For each problem, I try to follow a simple process:

1. Understand the problem
2. Identify the inputs and expected output
3. Break the problem into smaller steps
4. Develop the logic
5. Implement the solution in Python
6. Test the program with different inputs
7. Debug and improve the solution
